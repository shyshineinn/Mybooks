# 单用户、多设备同步（协议 3）

Web 是书库管理端；阅读进度、书签、标注和阅读时长在安卓设备之间同步。
保持单管理员、独立设备会话，不引入多人账户。协议 2 完整视图继续兼容旧客户端。

## 增量游标

`GET /api/sync/changes` 首次返回 `sync_version: 3`、`complete: true`、`library_id`、
`cursor`、全部在架书 `books`、明确删除事件 `deleted` 和阅读版本头 `reading`。
后续请求携带 `?cursor=上次游标`，返回 `complete: false` 与发生变化的条目。
空增量不是空书库，也不是删除命令；不能用缺少条目推断删除。

书目新增、修改、附件/标识符/自定义字段变化、删除和恢复都写入事务内的单调日志。
阅读版本变化使用独立事件，不推进书目的 `revision`。服务端在一致事务中读取视图与游标。
游标绑定书库、序号和随机检查点，可识别其他书库、未来游标及备份恢复后的序号复用。
日志保留最近 100000 条事件；过期或无效游标返回 `410 CURSOR_RESET`，客户端重新获取完整视图。
明确书目删除记录不随日志清理而丢失。

安卓只有在本批变更全部处理成功后才保存新游标。本地待上传修改单独合并处理，
不会因为远端增量为空而漏传；同步期间产生的新修改继续保留。
书库身份变化或版本倒退仍停止自动更新，完整回退不能绕过身份与版本保护。

## 安卓阅读数据

`GET /api/sync/reading/:id` 返回 `book_id`、`book_uuid`、独立的阅读 `revision` 和 `data`。
尚无阅读数据时版本为 0。`data` 有五个数组：

- `positions`：格式、正文 SHA-256、进度、定位、最后阅读时间与来源设备；不同正文保留独立位置。
- `bookmarks`、`notes`：独立 `syncId` 的书签、划线和笔记，保留标签、定位和样式快照。
- `reading_records`：按日期、设备标识保存时长，重复同步按同一记录的最大累计时长合并，不重复相加。
- `tombstones`：书签/标注的明确删除记录；缺少条目不代表删除。

`PUT /api/sync/reading/:id` 必须带 `library_id`、`expected_uuid`、
`expected_revision` 和完整 `data`。版本不符返回 `409 CONFLICT` 及 `current`，
身份变化返回 `409 IDENTITY_CHANGED`。每本书负载上限 4 MiB，每个数组最多 10000 条。
读取与写入始终要求会话，即使 `MYBOOKS_PUBLIC_READ=true` 也不会公开个人阅读数据。

安卓按上次基线、本机与服务器做逐条三方合并。不同条目自动合并，同一标注同时编辑、
删除与编辑并发、同一正文位置冲突时保留本机并提供明确选择，不比较设备时钟决定覆盖。
采用服务器只放弃冲突内容，非冲突项继续合并。落库时再次检查当前本机值，
请求期间的新编辑不会被回包覆盖，也不会被误认为已上传。
标注同样记录格式和正文校验值。不匹配正文时保留可读文字，但暂停高亮与定位跳转；
匹配正文下载后恢复。更换正文前尚未上传的位置按旧正文保留，不会被重新归到新正文上。

打开书籍使用本机已保存的位置；同步触发与 WebDAV 一致，不增加打开前检查或前台轮询。
已经打开的阅读页不强制跳转。定位只应用到匹配格式/正文的副本，正文尚未下载时可在下载完成后恢复。
服务器明确删除书目后，客户端核对 UUID 与版本，自动移除没有待上传修改的本机副本和云端占位；有未上传的书目或阅读数据时保留本机内容并提示，停止上传并清除已失效的冲突选择。后续增量为空时仍检查之前保留的已删除书目，避免遗留占位；空增量本身不产生删除指令。

## 正文断点续传

书目详情的文件项提供 `download_url`。新下载接口为
`GET /api/books/:id/files/:fileId/content?uuid=书目UUID`，返回强 `ETag`、
`X-Content-SHA256` 和 `Accept-Ranges: bytes`，遵循 `Range` / `If-Range`。
文件替换后验证器变化，续传请求返回完整 200，客户端丢弃旧前缀重新写入。

安卓保留 `.part` 与不含令牌的验证元数据，网络中断或进程结束后可继续。
严格检查 206 范围，完成后校验整份正文的长度与 SHA-256，再发布本机副本。
损坏前缀不会被接受；弱验证器或旧下载接口不进行不安全的拼接，仍可完整下载。
反向代理必须透传 Range、If-Range、ETag 和校验头，不得绕过附件认证。

## 保留的书目保护与兼容

书目 PATCH、PUT、DELETE 使用 `expected_revision` 与 `expected_uuid`；冲突返回 409 和 `current`。
本地排队删除保存操作时的 UUID 与版本，其他设备修改后停止删除。
同步缺少书目、空数组、网络失败都不是删除指令。删除事件在软删、硬删及合并事务中保存，
恢复同一本书时取消删除标记并推进版本。回填书目只修改元数据，不覆盖正文路径与阅读位置。

旧客户端继续使用无筛选的 `GET /api/sync/books` 协议 2 完整视图。
新安卓遇到旧服务端依次回退协议 2 与旧书目列表，保留旧协议删除限制；
不向未声明阅读能力的服务器上传阅读数据，界面提示升级后端并保留待上传数据。

## 升级与验证

后端数据库升级到 v18；安卓仍为 Room v22，新增同步状态使用现有状态表。
应用版本保持 2.3.10 / 2310。先备份数据库与附件、升级后端，再安装新版安卓。
恢复或回退程序时使用相匹配的数据库备份；本地构建不表示已部署或发布。

重点验收：空增量、长期离线与游标失效、删除/恢复、离线编辑、两台安卓合并标注与时长、
同项冲突选择、请求期间继续编辑、正文版本不匹配、中断续传和文件替换后的完整重下。

## 安卓自动与手动同步

服务器与 WebDAV 使用相同的模式按钮、四类同步内容选择、连接状态、测试、立即同步、停用和清除配置布局；配置、凭据与网络协议各自独立。连接后不显示重新配置按钮。切换模式仅保存选择，不额外触发同步或取消正在运行的同步。

自动模式按 WebDAV 的事件触发：应用启动、退出阅读、应用退后台排入完整同步；阅读数据变化防抖 5 秒后同步阅读数据与所选便携状态。没有定时轮询，也没有打开书籍前的额外网络检查。退出阅读先保存最终位置和时长，由应用级协程完成，避免阅读页销毁取消保存。手动模式保存本机，点击“立即同步”交换数据。

后台任务等待联网，临时故障从三十秒开始指数退避，最多重试四次。会话、冲突与权限问题保留本机数据并提示处理。触发不代表立即完成，仍取决于网络和系统调度。

## 四类数据与普通导入

- 书籍文件：普通导入先选择文件，逐本打开完整信息弹窗，确认后先保存本机；自动模式再上传并关联服务器，手动模式等待立即同步。同步封面和书目信息；正文按需下载并支持续传。
- 个人资料与应用设置：沿用 WebDAV 的便携偏好导出规则，同步昵称、头像、阅读设置及其字体/背景资源，不同步设备凭据和同步连接配置。
- 书库组织：同步文件夹、标签、书籍归属、收藏和置顶等布局信息。
- 阅读数据：同步进度、书签、标注、标签目录与各设备阅读时长。逐本阅读接口继续执行三方合并与冲突选择，不被全局设置快照覆盖。

设置页不再提供上传/下载页面或上传按钮；书架共用立即同步入口，不提供服务器专用下拉刷新或旧“上传到服务器”导入分支。已关联书籍同步本机修改和阅读数据。新书正文校验成功后原位关联，保留进度、标注、时长、标签、文件夹、正文路径和按书设置；中断上传保留原书和重试标识，重试复用已创建书目。

## 私有便携状态

`GET/PUT /api/sync/state` 返回/提交独立的全局 `revision`，PUT 携带 `library_id`、`expected_revision` 和 `data`。协议 3 增量头声明 `portable_sync` 与 `portable_revision`，状态改变不推进书目版本。并发冲突重新获取、按 WebDAV 的便携合并规则合并后重试；落库前再次保留本机新编辑和正文身份。旧服务端未声明能力时保留本机资料并提示升级。

便携快照上限 8 MiB。资源通过 `PUT /api/sync/state/assets/:sha256.ext` 以二进制上传，上限 64 MiB，内容必须匹配文件名 SHA-256。`GET/HEAD` 支持强校验与 Range/If-Range，接口始终要求会话；先上传资源，再条件提交引用它的快照。资源位于持久化根目录 `data/mobile-state-assets/`，备份必须同时保留。

## 书架删除

服务器和 WebDAV 共用同一确认框及顺序规则。仅本机删除取消下载并移除本机正文；服务器仍有该书时保留云端占位、关联和阅读数据，已确认服务器删除时则完整移除本机记录与失效同步状态。普通“本机与云端”先删云端，云端失败保留本机；强制删除先清理本机，再尝试云端，失败保留待处理请求。服务器请求仍携带操作时的 UUID 和 revision，不能绕过其他设备修改产生的冲突。

清除服务器配置仅撤销当前会话、清除连接凭据并停用同步；保留全部书籍及其 ID、正文、封面、阅读数据、同步基线与待处理记录。原服务器地址仅作为书籍关联身份保留，重新登录相同服务器时复用原书目，不重复上传正文；继续校验书库 ID、UUID 和版本。保留旧关联期间仍禁止直接切换到另一个服务器，避免数字 ID 混库。
