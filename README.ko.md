# My books Android

Lumi 기반 Android 전자책 리더입니다. 로컬 독서, WebDAV, 직접 운영하는 My books 서재를 지원합니다.

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

## 주요 기능

- EPUB, PDF, TXT, MOBI, CBZ 읽기 및 서재 관리.
- 하이라이트, 메모, 책갈피, 음성 읽기, 독서 통계.
- WebDAV 동기화, 로컬 백업 및 복원.
- 자체 서재 로그인, 도서 정보 동기화, 충돌 처리.

## 사용 및 개발

APK는 이 저장소의 Releases에서 받고 사용할 서버를 직접 설정하세요.
[연결 및 빌드 안내](devdocs/mybooks-open-source.md) · [동기화 규약](devdocs/mybooks-sync-protocol.md) · [기여 안내](CONTRIBUTING.md)

자체 백엔드는 아직 읽기 위치, 책갈피, 주석 동기화를 지원하지 않습니다. WebDAV 동기화는 별도 기능입니다.
